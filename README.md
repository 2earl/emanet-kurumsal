# Emanet Kurumsal

Emanet for creditors: banks, asset management companies and their law firms add the vehicles
they may have taken, follow each case, and get notified when a vehicle reaches a custodian car
park. Web app and API at emanet-kurumsal.2earl.com.

Built on [Emanet core](https://github.com/2earl/emanet-core); sign-in with login.2earl.com.

Emanet is a private service, not a public authority.
